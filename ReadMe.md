# Target Journals

> Ranking data updated on **2026-07-30**.
>
> - **新锐 (2026)**: LetPub《新锐期刊分区表》（2026 年 3 月发布）的**大类学科分区**。点击分区可打开对应的 LetPub 期刊页。
> - **JCR (2026)**: 2026 Journal Citation Reports（2025 citation data，2026-06-17 发布）。期刊涉及多个 JCR 学科时，本表展示最佳 JIF Quartile；点击分区可查看期刊记录。
> - **IF / Annual papers**: LetPub 2025–2026 最新 IF 与当前“年文章数”快照。
> - **CCF (2026)**: CCF 推荐国际学术会议和期刊目录（第七版）；`—` 表示该版目录未收录。
> - `未收录` 表示对应分区来源的当前版本没有该刊记录。
> - JCR 链接指向 Journal Metrics 的期刊记录；投稿、考核等高风险用途请再通过 Clarivate JCR 官方数据库核验。

LetPub 新锐分区可用仓库内的抓取脚本复核：

```bash
python -m pip install -r requirements.txt
python scripts/fetch_letpub_rankings.py
```
